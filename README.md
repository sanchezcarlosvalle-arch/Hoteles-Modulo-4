# Guía Hoteles - Módulo 4

Guía de hoteles con Bootstrap 4, SASS, jQuery y scripts npm.

Autor: Carlos Osmany Sanchez Valle

Curso: [Diseñando páginas web con Bootstrap 4](https://www.coursera.org/learn/disenando-paginas-bootstrap4/home/welcome) (Coursera) - Módulo 4.

## Uso

```
npm install
npm run scss
npm run dev
npm run build
```

- `npm run watch:scss` recompila el SCSS al guardar.
- `npm run clean` borra `distri`.
- `npm run build` compila el SCSS comprimido y deja el sitio listo en `distri/`.
